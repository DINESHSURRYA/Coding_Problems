Let's write out the sequence of vertices along the path from the root to vertex <span class="tex-span"><i>v</i></span>: <span class="tex-span"><i>u</i><sub class="lower-index">1</sub>, <i>u</i><sub class="lower-index">2</sub>, ..., <i>u</i><sub class="lower-index"><i>k</i></sub></span> <span class="tex-span">(<i>u</i><sub class="lower-index">1</sub> = 1;&nbsp;<i>u</i><sub class="lower-index"><i>k</i></sub> = <i>v</i>)</span>.
