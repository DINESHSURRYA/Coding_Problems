After that, they numbered each other with numbers from <span class="tex-span">1</span> to <span class="tex-span"><i>n</i></span>, inclusive. Each fool got a unique number. The fools decided not to change their numbers before the end of the fun.</p><p>Every fool has exactly <span class="tex-span"><i>k</i></span> bullets and a pistol. All shots of the round are perfomed at one time (simultaneously). If there is exactly one living fool, he does not shoot.</p><p>Let's define a <span class="tex-font-style-it">situation</span> as the set of numbers of all the living fools at the some time.
